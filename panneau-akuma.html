Connexion au bot

Le token reste sur ton téléphone. Il est envoyé à Discord uniquement via ton propre relais Cloudflare.

  1. Sur discord.com/developers/applications, crée une application puis un Bot. Copie son token et active Server Members Intent.
  2. Invite le bot avec les permissions : gérer les rôles, gérer les pseudos, gérer les salons, voir les salons, envoyer des messages.
  3. Dans les rôles du serveur, place le rôle du bot au-dessus de tes membres.
  4. Active le mode développeur de Discord, puis appuie longuement sur ton serveur : Copier l'identifiant.
